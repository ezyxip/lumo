# MESH-уравнения в формулировке Naphtali-Sandholm (V0)

Закрывает ишью #3. Фиксирует точную систему уравнений, которую кодогенератор
(ишью #5) будет превращать в C99-код. Общая постановка — в [problem.md](problem.md),
здесь — потиповые уравнения, состав вектора Ньютона, подсчёт размерности
и проверки (ручная + численная).

**Связь с problem.md.** Там вектор `N(2C+3)+2` с `D`, `W` как неизвестными
и единообразным `(x,y,T,L,V)` на всех ступенях. Здесь зафиксирован
уточнённый V0-вариант (причина — разбор сиротских переменных, см. раздел 6):
`D` — заданный спек входа модели (подстановка, как `F`);
кубовый продукт `B` (в problem.md — `W`) — переменная Ньютона, занимающая
слот `L_N`; `V_1` при total condenser исключён, его слот занимает `Q_D`;
`Q_W` — тоже неизвестная (выход). Эквивалентность по числу степеней
свободы — в разделе 6.

**Обозначение.** Кубовый продукт — `B` (bottoms), чтобы не путать с `W_j` —
паровым боковым отбором в общих формулах раздела 2. В problem.md кубовый
продукт назывался `W`; здесь везде `B`.

**CMO-референс (`solver` ветка) из документа исключён**: он считает
редуцированную S+M систему без H-уравнений и является черновиком, а не ТЗ
для кодогенератора.

## 1. Обозначения и вектор Ньютона

- Ступени `j = 1..N` сверху вниз: 1 — конденсатор, N — кипятильник.
- Компоненты `i = 1..C` (V0: `C = 2..3` по валидатору топологии).
- Границы: `L_0 = 0`, `V_{N+1} = 0`.
- Внутренние ступени (`1 < j < N`): `x_{i,j}`, `y_{i,j}`, `T_j`, `L_j`, `V_j`
  (`2C+3` переменных).
- Граничные замены (суть разделов 3.1 и 3.5, здесь — итог):
  - total condenser: потока `V_1` физически нет (ступень 1 пар не покидает),
    поэтому `V_1` — не переменная; её слот занимает `Q_D`
    (неизвестная тепловая нагрузка конденсатора, выход модели).
    Формальные `y_{i,1}` и E₁ сохраняются (см. раздел 3.1).
  - kettle/thermosiphon: отдельного потока `L_N` «вниз в никуда» нет —
    жидкость, покидающая ступень `N` вниз, и есть кубовый продукт, поэтому
    `L_N ≡ B` (одна переменная, не две); плюс неизвестная `Q_W`.
  - partial condenser: паровой продукт реален, `V_1 ≡ D` (алиас, зеркально
    `L_N ≡ B`), плюс неизвестная `Q_D`.

Итого переменные Ньютона: все `x, y, T, L, V` внутренних ступеней, на концах —
с заменами выше, плюс глобальные `B` (в слоте `L_N`), `Q_D`, `Q_W`.
`D` — заданный спек (подстановка, не переменная).

## 2. Общее MESH-ядро (одинаково для всех ступеней)

**M — материальный баланс по компоненту `i`:**

```
L_{j-1} x_{i,j-1} + V_{j+1} y_{i,j+1} + F_j z_{i,j}
  - (L_j + U_j) x_{i,j} - (V_j + W_j) y_{i,j} = 0
```

`F_j` — питание (ненулевое только на ступенях подачи, `∈ [2..N-1]`
по ADR-0002); `U_j`, `W_j` — жидкостной/паровой боковые отборы (ноль
везде, кроме side-draw ступеней; заданные входы модели, не переменные).

**E — равновесие (идеальная модель, закон Рауля):**

```
y_{i,j} - K_{i,j} x_{i,j} = 0,  K_{i,j} = Psat_i(T_j) / P_j
lg Psat_i = A_i - B_i / (C_i + t_j),  P в мм рт.ст., t в °C
```

Константы Antoine — вход компилятора (Level 1), единицы строгие
(ADR-0003). Давление `P_j`: в V0 — const по высоте (во всех примерах);
схема допускает `linear_drop` — тогда профиль задан, не переменная.

**S — суммирование долей:**

```
Σ_i x_{i,j} - 1 = 0,  Σ_i y_{i,j} - 1 = 0
```

**H — тепловой баланс:**

```
L_{j-1} h_{j-1} + V_{j+1} H_{j+1} + F_j h_{F,j}
  - (L_j + U_j) h_j - (V_j + W_j) H_j - Q_j = 0
```

`h_j = h(T_j, x_j)`, `H_j = H(T_j, y_j)` — идеальные энтальпии; конкретная
корреляция (полиномы Cp) фиксируется в ишью #4 вместе с модулем
термодинамики, здесь форма символьная. `h_{F,j}` — энтальпия питания
(`tF`, `z` из входа модели). `Q_j = 0` везде, кроме `j = 1` (`+Q_D`,
неизвестная) и `j = N` (`-Q_W`, неизвестная) — см. раздел 4.

## 3. Уравнения по типам ступеней

### 3.1. Total condenser (`j = 1`)

`L_0 = 0`; `V_1` не существует (весь пар со ступени 2 конденсируется) —
не переменная. Дистиллят `D` (задан) — жидкость состава `x_{i,1}`.
`Q_D` — неизвестная (раздел 4).

```
M:  V_2 y_{i,2} + F_1 z_{i,1} - (L_1 + D) x_{i,1} = 0
E:  y_{i,1} - K_{i,1} x_{i,1} = 0            (формальные y_{i,1}; ни на что кроме Sʸ₁ не влияют)
S:  Σx - 1 = 0, Σy - 1 = 0                  (Sʸ₁ — условие пузырька конденсата, держит T_1)
H:  V_2 H_2 + F_1 h_{F,1} - (L_1 + D) h_1 - Q_D = 0,  Q_D > 0 — отвод тепла
```

В V0 `F_1 = 0` всегда (фид только на `[2..N-1]`, ADR-0002).

### 3.2. Partial condenser (`j = 1`)

Конденсатор — равновесная ступень с физическим паровым продуктом:
`V_1 ≡ D` (дистиллят — пар состава `y_{i,1}`, `D` задан), `L_1` — флегма.

```
M:  V_2 y_{i,2} - L_1 x_{i,1} - D y_{i,1} = 0
E:  y_{i,1} - K_{i,1} x_{i,1} = 0            (физично: пар в равновесии с флегмой)
S:  Σx - 1 = 0, Σy - 1 = 0
H:  V_2 H_2 - L_1 h_1 - D H_1 - Q_D = 0,  Q_D > 0 — отвод тепла
```

### 3.3. Simple (`1 < j < N`, без фида и отборов)

`F_j = U_j = W_j = Q_j = 0`:

```
M:  L_{j-1} x_{i,j-1} + V_{j+1} y_{i,j+1} - L_j x_{i,j} - V_j y_{i,j} = 0
E:  y_{i,j} - K_{i,j} x_{i,j} = 0
S:  Σx - 1 = 0, Σy - 1 = 0
H:  L_{j-1} h_{j-1} + V_{j+1} H_{j+1} - L_j h_j - V_j H_j = 0
```

### 3.4. Feed (`j = f ∈ [2..N-1]`)

Simple + члены питания (`q`/`e`, `tF`, `z` — вход модели, Level 2):

```
M:  L_{j-1} x_{i,j-1} + V_{j+1} y_{i,j+1} + F z_i - L_j x_{i,j} - V_j y_{i,j} = 0
E, S — как simple
H:  L_{j-1} h_{j-1} + V_{j+1} H_{j+1} + F h_F - L_j h_j - V_j H_j = 0
```

При нескольких фидах (`feed_stages` — список) каждый пишется так же
со своим `F`, `z`, `h_F`.

### 3.5. Kettle reboiler (`j = N`)

`V_{N+1} = 0`. Отдельного потока `L_N` нет: жидкость, уходящая вниз
со ступени `N`, и есть кубовый продукт, `L_N ≡ B` (одна переменная).
`Q_W` — неизвестная (раздел 4).

```
M:  L_{N-1} x_{i,N-1} + F_N z_{i,N} - B x_{i,N} - V_N y_{i,N} = 0
E:  y_{i,N} - K_{i,N} x_{i,N} = 0
S:  Σx - 1 = 0, Σy - 1 = 0
H:  L_{N-1} h_{N-1} + F_N h_{F,N} - B h_N - V_N H_N + Q_W = 0,  Q_W > 0 — подвод тепла
```

В V0 `F_N = 0` всегда (ADR-0002).

### 3.6. Thermosiphon reboiler (`j = N`)

Структура MESH-уравнений та же, что kettle (раздел 3.5), включая
`L_N ≡ B` и неизвестную `Q_W`: различие термосифона — в гидравлике
циркуляции, а не в равновесных балансах. Детализация циркуляционного
контура — вне скоупа V0.

### 3.7. Side-draw (любая `j`, расход задан)

Общие M/H из раздела 2 с ненулевыми `U_j` (жидкостной отбор) или `W_j`
(паровой отбор). Расходы отборов — заданные входы модели (Level 2),
не переменные Ньютона. E/S — без изменений.

## 4. Тепловые нагрузки Q_D, Q_W — неизвестные (выходы модели)

`Q_D`, `Q_W` — **переменные Ньютона**, после сходимости — выходы модели
(наряду с `R` в Design-варианте, профилями и `B`). Обоснование — чистое:
H₁ содержит `Q_D` линейно с коэффициентом −1 и больше `Q_D` нигде
не встречается (диагональная пара «неизвестная ↔ уравнение»);
аналогично `Q_W` в H_N. Это ровно та замена, которая устраняет сиротский
столбец `V_1` (и держит квадратным кипятильник, см. раздел 6), ничего
не выбрасывая. Инженерно это и правильно для Rating: нагрузку
кипятильника обычно хотят получить, а не задавать. Проектирование полей
`model_input.json`/`model_output.json` — задача ишью #5.

## 5. Замыкание: Rating и Design (оба варианта полностью)

`D` — заданный спек входа модели (подстановка, как `F`). Стадийные
уравнения одинаковы в обоих вариантах; замыкающее добавляется **ровно
одно** — им Rating и Design и различаются, весь остальной вектор
и блочно-трёхдиагональная структура якобиана идентичны
(это и есть флаг кодогенерации `closure: reflux_ratio | product_purity`
из problem.md §6).

### 5.1. Rating — задано флегмовое число

```
L_1 - R · D = 0,  R = задано
```

Составы `x_{i,1}` (дистиллят) и `x_{i,N}` (куб), `B`, `Q_D`, `Q_W` —
результат решения.

### 5.2. Design — задан состав продукта

```
x_{light,1} - x_D^spec = 0,  x_D^spec = задано
```

`R` из уравнений исчезает (`L_1` — свободная переменная Ньютона),
после сходимости `R = L_1 / D` вычисляется как выход. Остальное —
как в Rating.

## 6. Размерность, ранг и отвергнутая альтернатива

Состав системы (Rating, total + kettle, без отборов):

- Неизвестные: ступени (`2C+3` каждая с заменами §1: на s1 нет `V_1`,
  зато есть `Q_D`; на sN нет `L_N`, зато есть `B` в его слоте и `Q_W`)
  плюс ничего глобального (`B` уже сидит в sN). `D` — подстановка.
- Уравнения: `N(2C+3)` стадийных + 1 замыкающее.
- **Кейс 5×2**: `7 + 3·7 + 8 = 36` переменных
  (s1: x2+y2+T+L+Q_D; s2–s4: 7; s5: x2+y2+T+B+V+Q_W),
  `35 + 1 = 36` уравнений. Система квадратная 36×36.
- Ранг полный: обе общие комбинации — массовая
  (`ΣM = F − D − B`, genuine через переменную `B`) и энергетическая
  (`ΣH = Fh_F − Dh_1 − Bh_N − Q_D + Q_W`, genuine через `Q_D`, `Q_W`) —
  настоящие ограничения, а не тождества, потерь ранга нет.
- Численная проверка: [mesh_rank_check.py](mesh_rank_check.py) собирает
  якобиан символьно (sympy) для N=3, C=2 и считает ранг в случайных
  точках: вариант B — 22×22, ранг 22 (8 точек). Запуск:
  `uv run --with sympy --with numpy python doc/mesh_rank_check.py`.

### Почему не вариант A (`Q_W` задан): несовместимость размерностей

При заданном `Q_W` получается 22 уравнения на 21 неизвестную
(N=3, C=2) — over-determined by construction: у матрицы 22×21 ранг
не может превышать 21 по линейной алгебре, и квадратный Ньютон тут
неприменим в принципе. Численно: ранг A ровно 21 во всех точках
(там же, mesh_rank_check.py). Это единственная причина отказа от A —
никаких рассуждений про «тонкую избыточность» не требуется
(и их здесь сознательно нет: 22 вектора в 21-мерном пространстве
зависимы всегда).

### Открытое наблюдение: обусловленность варианта B

На игрушечной термодинамике скрипта (гладкие stand-in `K(T)`,
линейные энтальпии — не настоящий Antoine): cond ≈ 1e7–1e9 без
масштабирования, ≈ 1e5–1e6 после physical scaling (проверено в скрипте).
Единицами измерения это не объясняется. Действия, не выводы:
1. повторить rank+cond на настоящей термодинамике из ишью #4
   (предлагается как критерий приёмки #4);
2. проверить гипотезу про «тонкий» столбец `Q_W` (нормы столбцов,
   cond без `Q_W`-блока);
3. это первая реальная мотивация фактора 6 Уровня 2 (статическое
   масштабирование переменных) — см. thesis_features_full.md.

## 7. Ручная проверка на N=3, C=2 (total + feed + kettle)

Конфигурация: ступень 1 — total condenser, ступень 2 — feed, ступень 3 —
kettle reboiler. Без боковых отборов. `D` задан.

| Ступень | Уравнения | Check |
|---|---|---|
| 1 (condenser) | M: `V_2 y_{i,2} − (L_1+D) x_{i,1} = 0`, i=1,2 (2 шт.) | `V_2` — со ступени 2 ✓, `L_0 = 0` использовано ✓, `V_1` нет как переменной ✓ |
| 1 | E: `y_{i,1} − K_{i,1} x_{i,1} = 0`, i=1,2 (2 шт.) | формальные `y_{i,1}` влияют только на Sʸ₁ ✓ |
| 1 | S: `Σx − 1`, `Σy − 1` (2 шт.); H с неизвестной `Q_D` (1 шт.) | Sʸ₁ — пузырёк конденсата, держит `T_1` ✓; 2+2+2+1 = 7 ✓ |
| 2 (feed) | M: `L_1 x_{i,1} + V_3 y_{i,3} + F z_i − L_2 x_{i,2} − V_2 y_{i,2} = 0` (2 шт.) | все потоки `1..3` существуют ✓ |
| 2 | E (2 шт.), S (2 шт.), H с `F h_F` (1 шт.) | 7 ✓ |
| 3 (reboiler) | M: `L_2 x_{i,2} − B x_{i,3} − V_3 y_{i,3} = 0`, i=1,2 (2 шт.) | `V_4 = 0` использовано ✓, `B` в слоте `L_3` ✓ |
| 3 | E (2 шт.), S (2 шт.), H с неизвестной `Q_W` (1 шт.) | 7 ✓ |
| closure | Rating: `L_1 − R·D = 0` / Design: `x_{1,1} − x_D^spec = 0` | 1 шт. ✓ |

Итого: `7 + 7 + 7 = 21` стадийное + 1 замыкающее = 22 уравнения
на 22 неизвестные
(`x: 6, y: 6, T: 3, L: 2 (L_1, L_2), V: 2 (V_2, V_3), B, Q_D, Q_W`).
Невисячих индексов нет (`L_0`, `V_4` исключены границами; `V_1`, `L_3`
исключены как несуществующие потоки), нулевых столбцов якобиана нет
(каждая переменная входит хотя бы в одно уравнение),
фид на ступени 2 ∈ `[2..N-1]` ✓.

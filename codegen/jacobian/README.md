# Генерация якобиана

`Generate(size)` возвращает `lumo_jacobian.h` и `lumo_jacobian.c`
Размер квадратной системы задаётся при генерации
Пакет не зависит от модели колонны, термодинамики или JSON

```c
int residual(const double *state, const void *context, double *out);

lumo_jacobian_fn compute = lumo_jacobian_numeric;
int status = compute(state, residual, model_context, NULL, matrix);
```

Функция невязки получает состояние и контекст модели
Отдельный контекст якобиана содержит настройки выбранного способа вычисления
Для численного варианта это `NULL` или `lumo_jacobian_numeric_options`
Будущие аналитические реализации и автоматическое дифференцирование
смогут использовать тот же тип функции и формат матрицы
Для их генерации потребуются сведения об уравнениях конкретной модели

`matrix[row * LUMO_JACOBIAN_SIZE + col]` содержит производную
невязки `row` по неизвестной `col`, без масштабирования
Память для плотной матрицы предоставляет вызывающий код
При ошибке матрица может быть заполнена частично, её нужно отбросить
Входные данные и настройки не должны пересекаться с выходным массивом

Реализованы центральные разности
Шаг равен `relative_step * max(abs(state[col]), variable_scales[col])`
Нулевой `relative_step` выбирает `cbrt(DBL_EPSILON)`
Без массива масштабов используются единицы
Масштабы должны быть положительными и конечными

Функция невязки возвращает статусы из `lumo_jacobian_status`
`DOMAIN_ERROR` обозначает выход за область допустимых состояний модели
Если одна проба выходит за область, используется односторонняя разность
Если обе пробы вне области, возвращается ошибка
Остальные ошибки передаются вызывающему коду
Дополнительная память на стеке растёт линейно с размером системы

Пакет `mesh` подключает эти файлы и переводит свои статусы через адаптер
Его публичный интерфейс якобиана сохранён

## Проверка

```bash
go test ./codegen/jacobian ./codegen/mesh
```

Отдельные C99 тесты используют полиномиальные системы с известными
производными и проверяют работу контекстов, границы области и ошибки
Интеграционные тесты `mesh` проверяют якобиан и Ньютон для колонны

# Начальное приближение

`Generate(cfg)` создаёт `lumo_initialguess.h` и `lumo_initialguess.c`
Поле `Files.Mesh` содержит остальные шесть файлов MESH, термодинамики и якобиана
Все восемь файлов компилируются вместе

```c
double state[LUMO_MESH_SIZE];
lumo_initialguess_fn initialize = lumo_initialguess_linear_T_x;
int status = initialize(&operating, state);
```

`operating` содержит подготовленные расходы, мольные составы и энтальпии
подач, расход дистиллята и молярное флегмовое число
Его можно получить из [prepare](../prepare/README.md)
Данные режима меняются при запуске, устройство колонны фиксируется при генерации

## Стратегия linear_T_x

Сначала вычисляется средний состав всего питания с весами по молярным расходам
При давлении колонны находится его температура начала кипения и состав пара
Отклонение этого состава пара от среднего питания задаёт направление обогащения
Оценка продуктов сохраняет общий материальный баланс компонентов

```text
F = sum(F_feed)
B = F - D
direction = 2 * (y_average - z_average)
xD = z_average + (B/F) * strength * direction
xB = z_average - (D/F) * strength * direction
```

Начальная сила обогащения ограничивается единицей и запасом до нулевых долей
Если температуры кипения оценённых продуктов вне диапазона свойств,
обогащение уменьшается вдвое, до 32 попыток
Последняя попытка использует одинаковый средний состав обоих продуктов
Если уже среднее питание нельзя привести к началу кипения в диапазоне свойств,
возвращается ошибка термодинамики

Температуры и жидкие составы линейно интерполируются между продуктами
Составы пара интерполируются между равновесными составами на границах
Все составы нормированы, равновесие внутри колонны предстоит обеспечить солверу
У конденсатора паровой состав является формальным, как в MESH

Для расходов используется приближение постоянного молярного парового потока
Все подачи на этом шаге условно считаются насыщенной жидкостью

```text
L_top = R * D
V = L_top + D
L_j = L_top + sum(F_feed at or above stage j)
L_bottom = B
```

Это приближение потоков применяется и при другом состоянии питания
Энтальпия реального питания остаётся в параметрах MESH и учитывается
при последующем расчёте невязки
Нулевой флегмовый расход допустим при R = 0

QD и QW выбираются из тепловых балансов конденсатора и кипятильника
Их знаки не ограничиваются, поскольку профиль ещё является приближением
Проверяются конечность полного вектора и возможность вычислить невязку MESH
При ошибке выходной массив сохраняется
Возвращаются статусы термодинамики и MESH

Стратегия является эвристикой, сходимость для любого режима не гарантируется
Тип `lumo_initialguess_fn` позволяет подключить другую стратегию
через тот же интерфейс
Выбор стратегии из `model_input.json` подключит будущий слой запуска

## Проверка

```bash
go test ./codegen/initialguess
```

Тесты проверяют бинарные и трёхкомпонентные смеси, три и пять ступеней,
несколько подач, крайние расходы продуктов, чистое питание, R = 0,
узкий диапазон температур и неизменность выхода при ошибках
Проверяются нормировки, линейность профилей, общие материальные балансы
и тепловые балансы границ

На независимом эталонном случае MESH тестовый Ньютон запускается из
сгенерированного приближения и сходится к сохранённому решению
Используется существующий тестовый решатель из `mesh/testdata/nonlinear`
Это локальная проверка одной стратегии, рабочий солвер остаётся отдельной задачей

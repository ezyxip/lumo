# Подготовка питания и режима

`Generate(cfg)` создаёт `lumo_prepare.h` и `lumo_prepare.c`
Поле `Files.Mesh` содержит невязку, якобиан и термодинамику
Все восемь C99 файлов нужно записать в одну папку и скомпилировать вместе

Компоненты и места подач фиксируются при генерации
Расходы, составы и тепловые состояния питания задаются при каждом запуске

```c
struct lumo_prepare_input input = {
    .feeds = {{
        .flow = 100,
        .flow_unit = LUMO_FLOW_KMOL_H,
        .composition_basis = LUMO_COMPOSITION_MOLE,
        .fractions = {0.5, 0.5},
        .state = LUMO_FEED_SATURATED_LIQUID
    }},
    .distillate_flow = 50,
    .distillate_unit = LUMO_FLOW_KMOL_H,
    .reflux_ratio = 2.5
};
struct lumo_mesh_operating operating;
int status = lumo_prepare_operating(&input, &operating);
```

Пример описывает бинарную смесь с одной подачей
Массивы следуют порядку `Files.Mesh.Thermo.ComponentIDs` и `Files.Mesh.FeedIDs`
Слой чтения JSON должен сопоставить ключи с этими массивами
Здесь реализован C-интерфейс подготовки, чтение JSON в исполняемой программе
будет отдельным слоем

Поддержаны `mol_s`, `kmol_h`, `kg_h` для питания и массовые или мольные доли
Доли должны лежать в [0, 1] и суммироваться в единицу с допуском `1e-10`
После проверки небольшая погрешность суммы нормализуется
Массовые доли переводятся по молярным массам компонентов

Тепловое состояние вычисляется при постоянном давлении колонны

- `LUMO_FEED_SATURATED_LIQUID` находит температуру начала кипения
- `LUMO_FEED_TEMPERATURE` использует `state_value` как температуру в K
- `LUMO_FEED_VAPOR_FRACTION` использует `state_value` как мольную долю пара

Термодинамика определяет фазовые составы и энтальпию питания
В `lumo_mesh_operating` записываются общий мольный состав, расход в моль/с
и энтальпия в Дж/моль, сохраняющая принятую систему отсчёта
Поддержано несколько подач, включая подачи на одну ступень

Расход дистиллята пока принимается в `mol_s` или `kmol_h`
`kg_h` возвращает `LUMO_PREPARE_UNSUPPORTED_SPECIFICATION`
Для него потребуется расширить замыкающее уравнение MESH с учётом
неизвестного состава дистиллята
Пересчёт по составу питания был бы некорректен

При ошибке выходная структура сохраняет исходные значения
Ошибки термодинамики передаются вызывающему коду
Начальное приближение и солвер этот модуль не строит

## Проверка

```bash
go test ./codegen/prepare ./codegen/thermo
```

Тесты проверяют эквивалентность единиц и базисов составов, три способа
задания состояния, несколько подач, ошибки и неизменность выхода при ошибке
Подготовленные параметры подставляются в независимое решение из теста MESH
Невязка остаётся близкой к нулю
Калорические свойства этого примера синтетические
